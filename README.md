# Vulnerability Assessment Report

## Website Tested

| Field | Information |
|---|---|
| **Target** | Google Firing Range |
| **URL** | https://public-firing-range.appspot.com/ |
| **Type** | Publicly accessible web application designed for web security testing and scanner evaluation |

## Tools Used

| Tool | Function |
|---|---|
| **OWASP ZAP** | Conducted passive web security assessment and detected security weaknesses such as missing HTTP security headers and configuration-related issues |
| **Nmap** | Performed network reconnaissance to identify open ports, active services, and basic exposure information of the target system |
| **Browser Developer Tools** | Reviewed HTTP headers, monitored network activity, and examined browser-side responses |
| **Canva** | Prepared and visually formatted the final assessment report |
